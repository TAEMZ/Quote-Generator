# 🎬 MOVIE QUOTE GENERATOR

A modern web app where users can submit, rate, comment on, and search for movie quotes. Fully responsive with threaded discussions, quote analytics, and real-time updates.

---

## ✅ FEATURES

| Feature              | Description                                  |
|----------------------|----------------------------------------------|
| 💬 Threaded Comments  | Users can reply to quotes and to each other  |
| 📊 Quote Analytics    | Visual breakdown of upvotes and downvotes    |
| 🎥 Add Favorite Movie | Save your favorite movies to your profile    |
| 🔍 Search Function    | Find quotes or movies instantly              |
| 🧠 Generate Quotes    | Auto-generate quotes based on your filters   |
| ✍️ Submit Your Own    | Add original or favorite quotes              |
